Each row is one person in one wave (person x wave panel).
Variables labelled "time-varying" change value across a person's waves.
Variables labelled "time-invariant" are stable across all of a person's rows.

------------------------------------------------------------------------------
SECTION 1: PANEL IDENTIFIERS
------------------------------------------------------------------------------

person_id         [time-invariant] String key combining 1968 interview number
                  and person number, joined by "_" (e.g. "4_3").
                  Use this as the individual identifier for panel regressions.
                  Formed as: paste(ER30001, ER30002, sep = "_")

ER30001           [time-invariant] 1968 interview number. First part of the
                  stable PSID person ID. Numeric.

ER30002           [time-invariant] Person number within the 1968 family.
                  Second part of the stable PSID person ID. Numeric.
                  person_id = ER30001 * 1000 + ER30002 (for merging with
                  other PSID extracts that use the numeric form).

year              [time-varying]  Survey wave year: 2019, 2021, or 2023.

------------------------------------------------------------------------------
SECTION 2: TIME-INVARIANT PERSON CHARACTERISTICS
------------------------------------------------------------------------------

ER32000           [time-invariant] Sex of individual (biological sex recorded
                  at PSID entry).
                  1 = Male
                  2 = Female

ER32006           [time-invariant] Sample membership status.
                  1 = SRC original sample
                  2 = SRC 1969 mover sample
                  3 = Census SEO low-income sample
                  4 = Other

SECTION 5: WELL-BEING FREQUENCY BATTERY (Section B18)

Items from the Keyes Mental Health Continuum Short Form (MHC-SF).

       8 = DK

                   belonged to a community (like a group of friends, your

                   society is becoming a better place for people?

SECTION 15: LAGGED WELL-BEING VARIABLES
------------------------------------------------------------------------------
These variables carry each person's PRIOR-WAVE value of the corresponding
well-being measure. Lags are created within-person after sorting by year:
  2019 row -> lag = NA  (no prior wave)
  2021 row -> lag = person's 2019 value
  2023 row -> lag = person's 2021 value
Constructed via dplyr::lag() grouped by person_id in Final_paneldata.R.
Missing codes are inherited from the source variable (see Sections 5, 6, 13).

wb_interest_lag        Prior-wave value of wb_interest        (B18B)

wb_belong_lag          Prior-wave value of wb_belong          (B18E)

==============================================================================
MISSING VALUE CONVENTIONS (RAW PANEL)
==============================================================================

This file (psid_tas_panel.csv) retains RAW PSID codes. Do NOT apply
automatic NA rules — each variable uses its own codes for missing /
inapplicable values:

  General missing:   8 = DK, 9 = NA/refused (1-digit items)
                    98 = DK, 99 = NA/refused (2-digit items)
  Inapplicable:      0 = Inap (question not applicable, e.g. not enrolled)
  Continuous caps:  99, 999, 9999... = DK/NA (match digit length)

For analysis-ready recoded variables (female, emp1_working, race dummies,
log_income, health_clean, etc.) use psid_tas_panel_clean.csv.
